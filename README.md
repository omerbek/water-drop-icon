# Water Drop Icon / Vektör durum simgesi

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/water-drop-icon/).

Bir damla ve onay işaretini çözünürlükten bağımsız çiz.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Kontur kalınlığı
- Onay başlangıcı (s)

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Adjust stroke width and the timing of an animated check mark.

Open [the live tool](https://omerbek.github.io/water-drop-icon/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
